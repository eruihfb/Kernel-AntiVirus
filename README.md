# 🛡️ Kernel Antivirus for macOS

Real-time download scanner, multi-folder daily scanner, quarantine vault, native macOS menu bar shield, and `kv` terminal CLI.

## Setup
1. Get a free API key from VirusTotal.
2. Open Terminal, `cd ` into this folder (select folder and press "Option+Command+C" ("⌥+⌘+C"), and run:
   chmod +x install.sh uninstall.sh && ./install.sh
3. Paste your API key when prompted, then open a new Terminal window and type `kv help`.
